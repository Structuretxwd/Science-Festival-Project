联网大模型设置

Key 只保存在本机浏览器（localStorage），不会上传到任何服务器或第三方。 仅当你点击「测试连接」或发起联网提问时，它才会随该次请求发送给你配置的大模型服务。

留「自动匹配」时，系统会用你填的 Key 依次探测各服务商，第一个返回成功的即为当前服务商； 也可以手动指定，这样 Key 只会发给这一家。

关于两种模式

  • 离线模式：检索本地知识库作答，速度快、完全离线，答案带出处与核实标记。
  • 在线模式：把知识库检索结果作为上下文交给大模型改写；知识库没收录的问题，则由大模型用通用知识作答并标明来源。

未通过的密钥不会启用在线模式，徽章会保持灰色或橙色。
